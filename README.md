# Escrow

Lock funds. Unlock trust.

Escrow is the escrow launchpad of Solana. Every coin launched on Escrow gets its own escrow vault. Holders lock tokens and earn a share of that coin's trading fees in SOL every 10 minutes, with longer locks earning more weight: 1x at 7 days up to 7.5x at 365 days.

- 60% of fees to the coin's lockers
- 30% to $ESCROW stakers
- 10% to the treasury

Escrow agreements let anyone lock tokens or SOL with on-chain release rules: time-locked, milestone, mutual, streaming or reward.

## Files

- `index.html`: the whole site (HTML, CSS and JavaScript in one file)
- `logo.png`: the Escrow logo, also used as the favicon

## Deploy with GitHub Pages

1. Push these files to the root of your repository.
2. Go to Settings → Pages, choose Deploy from a branch, pick `main` and `/ (root)`, then save.

It also works on Vercel, Netlify or Cloudflare Pages with no build step.
